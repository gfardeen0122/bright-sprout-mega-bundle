# Bright Sprout WordPress Theme

A modern, conversion-optimized landing page theme for educational worksheet products.

## Installation

1. Download all files and place them in a folder named `bright-sprout`
2. Zip the entire `bright-sprout` folder
3. Go to WordPress Admin → Appearance → Themes → Add New → Upload Theme
4. Upload the zip file and activate

## Setup Instructions

### 1. Add Images
Place your images in `assets/images/` folder:
- `hero-child.jpg` - Hero section image
- `parent-child-learning.jpg` - Benefits section image

### 2. Customize Content
Go to **Appearance → Customize** to edit:
- Hero section title and subtitle
- Pricing (current price, original price)
- Purchase link

### 3. Add Purchase Link
In the Customizer under "Pricing" section, add your Instamojo/Razorpay payment link

## Customization

### Changing Colors
Edit `style.css` CSS variables at the top to match your brand colors.

### Adding More Content
Edit `index.php` to add or modify sections.

### Advanced Customization
- `functions.php` - Theme functionality and customizer options
- `assets/js/main.js` - JavaScript interactions
- `header.php` & `footer.php` - Site structure

## Requirements

- WordPress 5.0 or higher
- PHP 7.4 or higher
